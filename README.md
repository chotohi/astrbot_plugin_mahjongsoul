# astrbot_plugin_mahjongsoul

从 [nonebot_plugin_majsoul](https://github.com/bot-ssttkkl/nonebot-plugin-majsoul) 移植的 AstrBot 雀魂插件，支持玩家数据查询、最近对局和 PT 图，并新增可选 AI 锐评、密钥开关、接口诊断与限流处理。

维护者：**ChoToHi** · 当前版本：**v1.1.1** · Python **3.12+** · AstrBot **4.28.2+**

感谢原作者 **ssttkkl** 及上游贡献者。本项目是独立维护的 AstrBot 移植版，沿用 **AGPL-3.0**，不属于雀魂或牌谱屋官方项目。
战绩走势卡的可视化版式参考了 [majsoul-tracker](https://github.com/Nigheart/majsoul-tracker)（MIT）的图片卡设计。

## 功能

- 三麻、四麻个人数据查询，支持按房间、时间和最近场数筛选。
- 雀魂昵称绑定与解绑，绑定后可省略查询昵称。
- 最近对局文字列表及 PT 走向图，PT 图场次上限可配置，默认 2000 场。
- **可视化战绩走势卡**：940px 双栏。左栏段位分走势、素点走势、逐局 PT、顺位走势；右栏全局总结、顺位分布、连打 vs 散打、最长连打段、打牌时段；通栏关键指标对比、牌风雷达、详细档案。
- 战绩卡发完后可自动追加一张 **AI 锐评卡**（需配置 AI Key）。
- 可选 AI 锐评：通过 OpenAI 兼容接口简短点评数据。
- 缺少 AI Key 时自动关闭锐评；缺少牌谱屋 Key 时关闭 PT 走向查询与绘图。
- 管理员可检查密钥加载状态、功能开关及当前镜像；状态命令不暴露密钥，也不发送外部请求。
- 请求间隔至少 1.10 秒；401/403/429 停止自动重试，按发起命令的 QQ 用户独立等待，默认 3600 秒，可配置。

## 安装

在 AstrBot 插件管理页面选择从仓库安装，填写：

```text
https://github.com/chotohi/astrbot_plugin_mahjongsoul
```

安装后打开插件配置，按需要填写牌谱屋和 AI 密钥，保存并重载插件。

账号绑定保存在 `data/plugin_data/astrbot_plugin_mahjongsoul/`。升级时，如果新目录尚无绑定文件，会自动复制旧目录 `astrbot_plugin_majsoul` 中的绑定；已有的新目录绑定优先，旧文件保留。

也可以从本仓库下载源码 ZIP 后上传安装，或将完整项目放入 `data/plugins/astrbot_plugin_mahjongsoul/`，保证目录下直接包含 `main.py`、`metadata.yaml` 和 `_conf_schema.json`。依赖见 [requirements.txt](requirements.txt)，不需要安装 NoneBot。

## 密钥与功能开关

| 配置状态 | AI 锐评 | PT 走向查询 / 绘图 | 普通信息查询、账号绑定 |
| --- | --- | --- | --- |
| 两种 Key 均未配置 | 关闭，不请求 AI | 关闭，不发送 PT 查询请求 | 保留 |
| 仅配置 AI Key，且开启锐评 | 开启 | 关闭 | 保留 |
| 仅配置牌谱屋 Key | 关闭 | 开启 | 保留 |
| 两种 Key 均已配置 | 由锐评开关控制 | 开启 | 保留 |

“开启”表示允许发起请求，不代表密钥已被服务端接受。AI 还需正确的接口地址和模型名；普通信息查询同样受牌谱屋服务可用性及访问限制影响。AI Key 与牌谱屋 Key 不能混用。空白字符串及只有 Bearer 前缀的配置按未填写处理。

填入密钥后保存并重载插件。运行时自动关闭功能不会改写你的配置开关；补齐 Key 并重载后可恢复。关闭 `majsoul_ai_comment` 则始终不调用 AI，即使已填 Key。
另外，牌铺屋密钥需要自行申请。

## 命令

以下以 `/` 为前缀；是否需要唤醒或前缀取决于 AstrBot 配置。

| 命令 | 用途 |
| --- | --- |
| `/雀魂账号绑定 昵称` | 绑定昵称；省略昵称查看当前绑定 |
| `/雀魂账号解绑` | 解除绑定 |
| `/雀魂信息 [昵称] [筛选条件]` | 四麻个人统计 |
| `/雀魂三麻信息 [昵称] [筛选条件]` | 三麻个人统计 |
| `/雀魂对局 [昵称] [筛选条件]` | 四麻最近对局，默认 10 场，最多 50 场 |
| `/雀魂三麻对局 [昵称] [筛选条件]` | 三麻最近对局 |
| `/雀魂PT图 [昵称] [筛选条件]` | 四麻 PT 图，需牌谱屋 Key |
| `/雀魂三麻PT图 [昵称] [筛选条件]` | 三麻 PT 图，需牌谱屋 Key |
| `/雀魂PT走向查询 [昵称] [筛选条件]` | PT 图查询的别名，需牌谱屋 Key |
| `/雀魂战绩 [昵称] [筛选条件]` | **可视化战绩走势卡**，需牌谱屋 Key |
| `/雀魂接口状态` | 仅 AstrBot 管理员：查看 Key 加载状态和功能状态 |

`雀魂查询` 是信息查询别名；`雀魂PT推移图`、`雀魂PT走向图`、`雀魂PT查询` 也可触发 PT 图查询，支持三麻/四麻前缀。
`雀魂战绩` 同样支持三麻前缀（`/雀魂三麻战绩`）；筛选条件与信息查询完全一致。

筛选条件之间用空格分隔，可组合使用：

```text
/雀魂信息 示例昵称 玉南 最近30天
/雀魂三麻信息 示例昵称 最近100场
/雀魂三麻PT走向图 示例昵称 最近100场
/雀魂战绩 示例昵称 最近50场
```

- 房间：`金`、`玉`、`王座`、`东`、`南`、`金东`、`金南`、`玉东`、`玉南`、`王座东`、`王座南`；也支持 `玉之间` 等全称。
- 时间：`最近7天`、`最近2周`、`最近3个月`、`最近1年`。
- 场数：`最近100场`，也支持中文数字。
- 普通信息的最近场数筛选在未配置牌谱屋 Key 时可使用聚合统计定位时间范围，可能较慢；失败时可改用时间范围查询。这不提供无 Key 的 PT 走向查询。

## 配置

在插件配置页面填写以下字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `majsoul_paifuya_api_key` | 空 | 牌谱屋 Key；请求使用 Authorization: Bearer。留空关闭 PT 查询与绘图 |
| `majsoul_paifuya_cooldown_seconds` | `3600` | 牌谱屋 401/403/429 错误后的本地等待秒数，正整数；按 QQ 用户独立计时 |
| `majsoul_pt_max_games` | `2000` | PT 图最多场次，必须大于 0；未指定最近场数时也使用此值 |
| `majsoul_record_enabled` | `true` | 是否启用 `/雀魂战绩` 走势图 |
| `majsoul_record_max_games` | `50` | 走势卡最多局数，2~500；命令里「最近N场」超过时截断 |
| `majsoul_record_compare` | `true` | 是否附带「关键指标对比」与「牌风雷达」（多两次请求，失败自动跳过） |
| `majsoul_record_theme` | `dark` | 走势卡配色，`dark` / `light` |
| `majsoul_record_detail` | `full` | 走势卡详细程度：`full`（含逐局 PT、打牌时段、详细档案）/ `compact`（省掉这三块，约矮 18%） |
| `majsoul_record_ai_comment` | `true` | 战绩卡发完后是否追加 AI 锐评卡；还需开启 `majsoul_ai_comment` 并配置 AI Key |
| `majsoul_ai_prompt` | 猫娘锐评提示词 | 自定义 AI 系统提示词，支持多行；完整默认值见下方 |
| `majsoul_ai_comment` | `true` | AI 锐评开关；还需有效配置 AI Key 才会调用 |
| `majsoul_ai_api_base` | 空 | OpenAI 兼容 API 地址；空值使用 SDK 默认地址 |
| `majsoul_ai_api_key` | 空 | AI Key；留空自动关闭锐评 |
| `majsoul_ai_model` | 空 | 服务商支持的模型名称 |
| `majsoul_ai_timeout` | `60` | AI 请求超时，秒 |
| `majsoul_query_timeout` | `15.0` | 整体查询超时，秒；复杂筛选可适当增加 |
| `majsoul_font_path` | 空 | 自定义字体文件路径；留空使用内置字体。文件需在 AstrBot 所在环境中存在且可读，推荐使用绝对路径 |
| `advanced` | `{}` | 高级 JSON，对同名表单字段具有覆盖优先级 |

`advanced` 在页面文本框中需填写合法 JSON，例如：

```json
{
  "majsoul_query_timeout": 60,
  "majsoul_send_link": true
}
```

这里使用双引号和冒号，不能写成 Python 字典或 `字段=值`。不要将整份用户配置覆盖到 `_conf_schema.json`；该文件是配置表单定义。

### 默认 AI 锐评提示词

配置页面可直接编辑以下文本，不需要填写 role/content 或 Python 代码。

```text
你是一个雀魂猫娘。
你需要根据玩家的雀魂统计数据进行锐评。

要求：
- 说话要像猫娘一样
- 客观分析数据
- 有节目效果
- 可以玩梗
- 不要太长
- 80字以内
- 不要回复很多换行符
- 禁止 Markdown 和富文本
- 禁止使用 **加粗文本**
- 不要辱骂群友
- 重点分析打法问题
- 要给出问题的解决方案
```

PT 图超过单次容量时分批取数，每次最多 500 场，所有分页继续使用牌谱屋 Key 和原有限流规则。最终绘制最近的 `min(命令场数, 配置上限)` 场；数据不足时绘制已有记录。默认未指定场数时最多取 2000 场。大图或较慢网络若超时，可将 `majsoul_query_timeout` 增加到 60 秒或更高。

## 战绩走势卡

`/雀魂战绩 [昵称] [筛选条件]` 会拉取逐局记录并画成一张 PNG（940px 宽双栏：左栏走势、右栏结论、底部通栏对比）：

**左栏（走势）**

| 区块 | 内容 |
| --- | --- |
| 段位分走势 | 逐局局后段位分折线 + 面积；跨段处折线断开、画虚线并标注新段位名 |
| 素点走势 | 每局终局点数折线，25000 基准虚线（看「打得稳不稳」比段位分更直接） |
| 逐局 PT | 零轴上下分色的柱状，一眼看出哪几局在失血（`compact` 模式省略） |
| 顺位走势 | 最近 N 局顺位折线散点，一位金 / 二位银 / 三位橙 / 四位红（三麻三行） |

**右栏（结论）**

| 区块 | 内容 |
| --- | --- |
| 全局总结 | 平均顺位 / 一位率 / 顺位波动（含档位） / 平均素点 四宫格 |
| 顺位分布 | 一位～四位的次数与占比进度条 |
| 连打 vs 散打 | 连打段（≥3 局）与散打局的局数、均顺、净 PT 对比，并判定连打是否吃亏 |
| 最长连打段 | 局数、时长、均顺、净 PT |
| 打牌时段 | 深夜 / 上午 / 下午 / 晚间四段局数与均顺（`compact` 模式省略） |

**通栏**

| 区块 | 内容 |
| --- | --- |
| 摘要行 | 局数、平均顺位、一位率、连对率、最长连一位、段位分变化 |
| 关键指标对比 | 本人值（绿色优于均值 / 红色劣于均值）与同段位均值并排，三列 |
| 牌风雷达 | 进攻 / 防守 / 副露 / 打点 / 速度五维，50 = 同段位均值（`compact` 单独占通栏） |
| 详细档案 | 总对局、最近对战、统计跨度、日均局数、平均间隔、连打段数、各顺位占比、最长连一/连最下位、素点区间与均值（`compact` 省略） |

高度会随信息量自适应：图表按局数缩放，左栏再拉伸与右栏齐平。实测 2 局约 970px、6 局约 1048px、
12 局以上进入满载约 1170px（带指标与雷达约 1340px）。`majsoul_record_detail` 设为 `compact`
可再省约 18% 高度。

发送顺序是**先战绩卡、再 AI 锐评卡**（两条独立消息）。锐评卡内容：

| 区块 | 内容 |
| --- | --- |
| 头部 | 头像、昵称、段位徽章、统计范围 |
| 关键数据 | 平均顺位 / 一位率 / 四位率 / 最长连一位 / 段位分净变化小标签 |
| 锐评正文 | 模型输出的自然段文本，自动折行；自动剥离 Markdown 与 emoji（字体无 emoji 字形） |
| 页脚 | 所用模型名 + 「AI 生成，仅供参考」 |

锐评的输入是与卡片同口径的结构化事实（摘要、最近顺位序列、指标对比、牌风分），不是图片本身，
这样模型不会去「看图猜数」。锐评失败（Key 失效、超时、渲染异常）只补一句提示或退回纯文本，
**不会影响已经发出的战绩卡**。想关掉只发战绩卡，把 `majsoul_record_ai_comment` 设为 `false`。

口径说明：

- **局后段位分**由官方当前分**倒推**：牌谱屋逐局只给「本局段位」与「本局段位分变动」，
  故末局用 `search_player` 的当前分锚定，往前逐局减去变动；跨段那一局改用新段位初始分（该段位上限的一半）。
  曲线末端因此与面板「当前分数」一致。
- **顺位**按每局终局点数在同局内排名（与牌谱屋一致），不是用段位分变动反推。
- **连打分段**按相邻两局的间隔切分：间隔 > 30 分钟算另开一段，段内 ≥ 3 局计为「连打」，其余计为「散打」。
  牌谱屋没有房间/席位概念，只能按时间切——这也是各家战绩工具的通行做法。
- **顺位波动**报顺位标准差与定性档位（很稳 / 较稳 / 一般 / 波动大）；样本 < 5 局时只报「样本少」，
  因为 2~3 局的波动完全由运气决定，折算成 0~100 分只会误导。
- **时段分布**在总局数 < 8 或只落在一个时段时自动省略——样本太少时分时段没有统计意义。
- **段位均值**取自牌谱屋 `global_statistics_2`（同房间模式、同段位 level id），本地缓存 6 小时。
  `majsoul_record_compare` 关闭时整块跳过，不再请求该接口。
- **牌风分**为 50 基准的比值映射（比值 2 → 100 分，比值 0.5 → 0 分），仅用于横向比较，不是绝对值。
- 牌谱屋**不提供**逐手 AI 复盘数据，因此本插件没有 Rating / AI 一致率 / 恶手率这类指标；
  上表所有区块都由牌谱屋已有字段真实算出，不编造数值。
- 渲染失败（Pillow 缺失、字体异常等）会自动回退为一行文字摘要，命令不会因此报错。
- AI 锐评卡同理：画不出来就发纯文本锐评，不会因为绘图问题丢掉内容。

本地预览版式（不联网、不连机器人）：

```text
python tools/preview_card.py all               # 六张：战绩卡(full/compact) / 锐评卡 × dark / light
python tools/preview_card.py compact light x.png   # 只出 compact 版
python tools/preview_card.py ai light out.png      # 只出锐评卡
```

## 使用说明与限制

本项目已移除牌谱下载命令、账号登录及账号密码配置。

- 数据来自牌谱屋，查询覆盖范围和可用性由数据源决定。没有找到数据不等于账号没有玩过雀魂。
- 401/403/429 后按 `majsoul_paifuya_cooldown_seconds` 等待，默认 3600 秒；本地等待不再直接采用服务端可能返回的 86400 秒。以平台实例和发送者 QQ 用户 ID 标识用户，不按游戏昵称或群聊计时，同一用户的三麻、四麻查询共用自己的等待时间。其他用户失败不会影响你的倒计时，重复查询只显示剩余秒数，不延长等待。保存配置后重载生效；等待状态保存在内存中，重启后清空。
- 本地等待结束后可以再次发起请求，但服务端仍可能拒绝；填过 Key 仍被拒绝，需核实密钥及接口权限。插件停止自动重试，不会以匿名查询或更换镜像绕过授权拒绝。
- AI 功能启用后会将统计文本发送到你配置的模型服务。AI 锐评失败不会撤回已经发出的统计结果。
